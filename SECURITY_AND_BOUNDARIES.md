# Security, IP and disclosure boundaries

Status: public showcase policy  
Date: 2026-10-02

This repository is designed to be safe for broad external viewing.

## Public showcase

Allowed here:

- high-level explanations;
- diagrams;
- synthetic examples;
- selected proof-by-use summaries;
- public project links;
- maturity and limitation statements.

## Not included

The following remain private or controlled:

- engine source snapshots;
- executable runtime internals;
- technical contracts or schemas when they materially enable reconstruction;
- private skills and project mappings;
- partner deployment packages;
- private project traces;
- research-action material that could identify people;
- operational credentials or secrets;
- deployment know-how that is not intended for public release.

## Repository family

The public showcase is intentionally separate from:

- the private controlled technical kit;
- the private partner deployment package;
- local/runtime workspaces;
- research-action memory on Drive.

Public visibility of this showcase does not grant rights to the private Nexus codebase or private project material.
